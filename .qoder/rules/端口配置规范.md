# 端口配置规范

## 端口分配

| 环境 | 前端 | 后端 API | 说明 |
|------|------|----------|------|
| 生产环境 | 3000 | 8000 | 生产部署使用 |
| 开发环境 | 3100 | 8100 | 本地开发使用 |

## 强制规则

### 端口使用规范

1. **严格按端口分配表使用端口**：开发和部署必须严格按照上述端口分配表执行，禁止使用其他端口
2. **端口占用检查**：启动服务前必须检查目标端口是否被占用
3. **端口清理范围**：仅允许清理释放本规范中定义的端口（3000、8000、3100、8100），**禁止清理其他端口**，避免影响其他项目

### 端口检查与清理命令

```bash
# 检查端口占用
lsof -i :端口号

# 清理占用端口的进程（仅限本规范定义的端口）
kill -9 $(lsof -t -i :端口号)
```

### 可清理端口列表

以下端口可以执行清理操作：
- **3000** - 生产环境前端
- **8000** - 生产环境后端 API
- **3100** - 开发环境前端
- **8100** - 开发环境后端 API

## 启动命令

### 开发环境

**后端服务 (端口 8100)**
```bash
cd dev/backend
npm install  # 首次运行需要安装依赖
npm run dev
```

**前端服务 (端口 3100)**
```bash
cd dev/frontend
npm install  # 首次运行需要安装依赖
npm run dev
```

**统一启动（根目录）**
```bash
# 同时启动前端和后端
npm run dev
```

### 生产环境

**使用 Docker Compose 部署**
```bash
cd deploy
docker-compose up -d
```

**或单独构建运行**

后端服务 (端口 8000)
```bash
cd dev/backend
npm run build
# 编译产物输出到 prod/backend/dist/
```

前端服务 (端口 3000)
```bash
cd dev/frontend
npm run build
# 构建产物输出到 prod/frontend/dist/
```

## 配置文件

### 后端配置
- 配置模板: `dev/backend/.env.example`（提交至 Git，新人参考此文件创建自己的配置）
- 开发环境配置: `dev/backend/.env.development`（不提交至 Git，本地使用）
- 生产环境配置: `prod/backend/.env`（仅在服务器上，不提交至 Git）

### 前端配置
- 配置文件: `dev/frontend/.umirc.ts`
- 开发环境代理: `/api` -> `http://localhost:8100`
- 生产环境代理: 通过 nginx 配置 (`deploy/nginx.conf`)

## 环境架构

开发和生产已完全分离为独立的物理环境：

| 维度 | 开发环境 | 生产环境 |
|------|---------|----------|
| 位置 | 本地开发机 (macOS) | 云服务器 8.130.26.73 |
| 访问 | 本地直接运行 | SSH root@8.130.26.73 |
| 项目路径 | 本地工作区 | /www2/DevHub/supply-chain-dashboard |
| 运行方式 | npm run dev | Docker Compose 容器化 |

代码通过 Git 同步：本地 push → 生产服务器 pull → deploy.sh 部署。

## 数据库连接

| 参数 | 开发环境 | 生产环境 |
|------|---------|----------|
| 主机 | localhost | xinshutong-postgres（Docker 内网） |
| 端口 | 5432 | 5432 |
| 数据库 | xly_dashboard | xly_dashboard |
| 用户名 | postgres | postgres |
| 密码 | postgres | postgres |

**环境隔离**：开发和生产使用完全独立的数据库实例，互不影响。生产数据库容器运行在 Docker 内网中，不直接暴露到公网。

**外部数据源**：原 xinshutong 数据库已完全弃用，商品、库存、销售、欠款等业务数据统一通过舟谱云管家 API 获取（见 `dev/backend/src/services/erp-client/`）。

## 注意事项

1. 启动服务前请先检查端口是否被占用
2. 仅能清理本规范中定义的端口（3000、8000、3100、8100），不允许清理其他项目的端口
3. 检查端口命令: `lsof -i :端口号`
4. 开发环境和生产环境位于不同的物理机器，互不影响
5. 新增环境变量时，必须同步更新 `.env.example` 模板和生产服务器的 `.env` 文件
